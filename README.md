# Aksharvel — Marathi Literacy Learning App

**ET 617 | Group 04 | Nplusone Social Foundation**

Aksharvel is an offline-first Android application designed to support foundational Marathi literacy among primary-school learners in tribal and multilingual communities. It provides guided practice in recognising, pronouncing and writing Marathi letters through a visual, child-friendly interface that minimises dependence on written instructions.

The project is intended for use in Government ZP and Ashram schools in Palghar district.

## Features

- **Four learning modes:** hearing and tapping, dragging, tracing, and speaking aloud.
- **Marathi Varnamala:** audio support for all 50 letters, including normal- and slow-speed playback.
- **Icon-led interface:** visual prompts and icons help learners navigate without needing to read written Marathi instructions.
- **On-device assessment:** handwriting and pronunciation assessment are performed locally on the device.
- **Offline-first learning:** core learning activities do not require an internet connection.
- **Local progress tracking:** learner progress and streak information are stored on the device.

## Get the application

### Option 1: Install the submitted APK

1. Open the repository's [Releases](https://github.com/EAD-Labs/Group-4_2026/releases) page.
2. Download the latest Aksharvel APK asset.
3. Transfer the APK to an Android device running Android 7.0 (API 24) or later.
4. If prompted, allow installation from the source used to open the APK.
5. Install and launch Aksharvel.

The final submitted build is named `Aksharvel-v4-Date-debug.apk`.

### Option 2: Open and run the source project in Android Studio

1. Install Android Studio and the Android SDK.
2. Install Git LFS and initialise it:
   ```bash
   git lfs install
   ```
3. Clone the course repository:
   ```bash
   git clone https://github.com/EAD-Labs/Group-4_2026.git
   cd Group-4_2026
   git lfs pull
   ```
4. Open the `Aksharvel-Tactile` directory in Android Studio.
5. Allow Android Studio to sync the Gradle project and download the required dependencies.
6. Ensure that Android SDK Platform and Build Tools required by the project are installed.
7. Connect an Android device with USB debugging enabled, or start an Android emulator.
8. Select the `app` run configuration and click **Run**.

### Option 3: Build from the terminal

From the repository root:

```bash
cd Aksharvel-Tactile
./gradlew assembleDebug
```

The generated debug APK will be located at:

```text
app/build/outputs/apk/debug/app-debug.apk
```

To install it on a connected device:

```bash
./gradlew installDebug
```

`local.properties` is machine-specific and should be generated by Android Studio or configured locally with the path to the installed Android SDK. It is not committed to the repository.

## Validation status

The client reviewed successive application builds and provided feedback that informed changes to the interface, language and navigation. The client also reported an informal tryout with approximately 10–15 students, who responded positively and enjoyed using the application. Students reportedly recognised and requested the app through its logos and icons, even when they could not spell its name.

This informal tryout should be distinguished from the structured school field study. Systematic classroom observations and recognition-accuracy measurements on children's speech remain pending.
